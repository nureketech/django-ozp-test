# ПББ тест платформасы

Педагогтердің білімін бағалау (ПББ) тестін нақты форматта жаттықтыруға арналған Django платформасы. Бір сайтта бірнеше пән: информатика, көркем еңбек (ұл / қыз балаларға), математика. Әр тест — 50 сұрақ; уақыты пәнге байланысты (125 немесе 80 минут). Толық техникалық тапсырма — [TZ.md](TZ.md), көп пәнді режим — 10-бөлім.

## Жергілікті іске қосу (Windows)

Python 3.12 немесе одан жаңа нұсқасы қажет.

```powershell
# 1. Виртуалды орта және кітапханалар
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt

# 2. Баптаулар: .env.example файлын .env деп көшіру (DEBUG=True қалдырыңыз)
copy .env.example .env

# 3. Деректер қоры, пәндер мен тақырыптар, демо сұрақтар
.venv\Scripts\python manage.py migrate
.venv\Scripts\python manage.py load_subjects
.venv\Scripts\python manage.py load_demo

# 4. Әкімші жасау және серверді іске қосу
.venv\Scripts\python manage.py createsuperuser
.venv\Scripts\python manage.py runserver
```

Сайт: http://127.0.0.1:8000/ , басқару панелі: http://127.0.0.1:8000/admin/

Оқытушы беттері (`is_staff` қолданушыға): сұрақтар — http://127.0.0.1:8000/teacher/questions/ (Excel-ден импорт — `/teacher/questions/import/`), контексттер — `/teacher/contexts/`, банк толуы — `/teacher/bank/`, нәтижелер және CSV — `/teacher/results/`.

Студент беттері: кабинет — `/dashboard/`, тақырыптық жаттығу (бір тақырыптан 10 сұрақ, таймерсіз, дұрыс жауап бірден көрсетіледі) — `/practice/`.

Linux/macOS-та `.venv\Scripts\python` орнына `.venv/bin/python` жазыңыз.

## Студенттерді қосу (Excel, ИИН + код)

Сайтта тіркелу жоқ. Студенттерді тек әкімші (`createsuperuser` арқылы жасалған қолданушы) Excel файлынан импорттайды:

1. Алдымен топтар құрылады: http://127.0.0.1:8000/admin/ → «Топтар» → «Қосу» (атауы, пәні, оқыту тілі).
2. Навбардағы **«Студенттер»** (`/students/`, тек әкімшіге) → **«Excel-ден импорттау»** → «Үлгі файлды жүктеп алу». Бірінші парақтың бағандары: **Аты-жөні, Топ, ИИН** (1-жол — тақырыптар; екінші парақта бар топтардың тізімі).
3. Толтырылған файлды жүктеу. Қате болса (ИИН-нің бақылау цифры, топ жоқ, ИИН қайталанған), ештеңе сақталмайды — қателер жол нөмірімен көрсетіледі.
4. Сәтті болса, **«Аты-жөні, Топ, ИИН, Код»** файлы бірден жүктеледі. Код (8 цифр) тек осы файлда көрсетіледі — сақтап, студенттерге таратыңыз.

**«Студенттер» беті** (`/students/`): студенттер тізімі (топ бойынша сүзгі, аты-жөні не ИИН бойынша іздеу), әр студентке **«Өңдеу»** (аты-жөні, тобы, ИИН; коды өзгермейді) және **«Жаңа код»**.

**Бір студентті қолмен қосу:** «Студенттер» → **«Студент қосу»** — аты-жөні, топ, ИИН (тексерулер импортпен бірдей). Сақтағаннан кейін студенттің коды **экранда бір рет** көрсетіледі — жазып алыңыз немесе студентке беріңіз. ИИН бұрыннан бар болса, жаңа аккаунт жасалмайды — сол студенттің бетіне сілтеме шығады.

Студент кіру бетінде ИИН мен кодты енгізеді. Файлды қайта жүктесе, бар студенттің аты-жөні мен тобы жаңартылады, коды өзгермейді. Код жоғалса — тізімдегі **«Жаңа код»** батырмасы (жаңа код экранда бір рет көрсетіледі, ескісі жұмыс істемейді). Бүкіл топқа бірден — admin-дегі «Топтар» тізімінде «Топ студенттеріне жаңа код жасау» әрекеті (кодтар файлы жүктеледі).

## Сұрақтарды Excel-ден импорттау

Оқытушы (және әкімші) «Сұрақтар» бетіндегі **«Excel-ден импорт»** батырмасы арқылы сұрақтарды файлдан қоса алады; сұрақтар таңдалған пәнге жазылады.

- «Үлгі файлды жүктеп алу»: «Сұрақтар» парағы — тақырыпша (01–20), деңгей (A/B/C), тіл (kk/ru), контекст кілті, мәтін, код, A–D нұсқалары, дұрыс жауап (A–D), сурет; «Контексттер» парағы — кілт, атауы, тіл, мәтін, код, сурет; «Нұсқаулық» парағында пәннің тақырыпшалары.
- Қате болса, ештеңе сақталмайды. Банкте бұрыннан бар сұрақ (мәтіні, тілі, тақырыпшасы бірдей) қайта қосылмайды, сондықтан файлды толықтырып қайта жүктей беруге болады.
- Суреттер Excel ішінен бірге жүктеледі: суретті «Кірістіру → Суреттер → Ұяшықтардың үстіне орналастыру» арқылы қойып, сол жақ жоғарғы бұрышын ұяшыққа апарыңыз — сұрақ пен контекст суреті «Сурет» бағанына, жауап суреті сол жауаптың (A–D) ұяшығына. Суреті бар жауаптың мәтіні бос болуы мүмкін. Сурет — jpg/png/webp, 2 МБ-қа дейін; файл — 20 МБ-қа дейін.

## Оқытушыны қосу

Оқытушыны тек әкімші басқару панелінде қосады:

1. http://127.0.0.1:8000/admin/ → «Пайдаланушылар» → «Қосу».
2. Логин, құпия сөз, аты-жөні; **«Қызметкер мәртебесі»** (`is_staff`) белгісі.
3. Сол беттегі «Профиль» бөлімінде оқытушының **пәндерін** таңдау → «Сақтау».

Пәні жоқ оқытушы `/teacher/...` беттерінде «Сізге пән тағайындалмаған» хабарламасын көреді. Бар қолданушыны оқытушы ету үшін оның бетінде дәл осы белгі мен пәндерді қойса жеткілікті.

Оқытушы басқару панелінде тек **өз пәндерінің** тест сессиялары мен топтарын көреді, жасайды және өзгертеді (бөлек рұқсат тағайындау керек емес). Қолданушыларды басқару, жазбаларды өшіру — тек әкімшіге.

## Пәндер

Пәндер, тақырыптар мен тақырыпшалар `apps/quiz/data/subjects.json` файлында (TZ.md, 10-бөлім). Жүктеу:

```powershell
.venv\Scripts\python manage.py load_subjects                     # барлық пән
.venv\Scripts\python manage.py load_subjects --only mathematics  # бір пән
```

Команданы қайта іске қосуға болады (жазбалар жаңартылады). `load_topics` — бұрынғы команда, `load_subjects --only informatics` деген сөз. Тест уақыты пәннен алынады: информатика мен математика — 125 минут, көркем еңбек — 80 минут.

## Демо сұрақтар

`load_demo` командасы тексеруге арналған сұрақтарды (`is_demo=True`) тақырыптары жүктелген әр пәнге жүктейді: әр тіл үшін әр тақырыпшаға 6 үлгі сұрақ және 4 контекст × 5 сұрақ — әр пәнде толық тест нұсқасы құрылады. Сонымен қатар информатикада Python коды бар нақты сұрақтар, математикада формуласы бар сұрақтар мен жауаптары тек суреттен тұратын сұрақ бар.

```powershell
.venv\Scripts\python manage.py load_demo --subject mathematics   # тек бір пән
```

**Нақты пайдалануға дейін демо сұрақтарды міндетті түрде өшіріңіз:**

```powershell
.venv\Scripts\python manage.py load_demo --delete
.venv\Scripts\python manage.py load_demo --delete --subject mathematics   # тек бір пәннің
```

## Формулалар және жауаптағы суреттер

- Формуласы бар пәнде (`subjects.json`-да `"uses_formulas": true`, қазір — математика) формулалар **KaTeX** арқылы көрсетіледі: жол ішінде `\( ... \)`, бөлек жолда `\[ ... \]`, мысалы `\(\frac{1}{2}\)`. `$` белгісі қолданылмайды. Формула сұрақ, контекст мәтінінде және жауап нұсқаларында жұмыс істейді; KaTeX CDN-нен (`cdn.jsdelivr.net`) тек сұрақ көрсетілетін беттерде жүктеледі. Желі болмаса, мәтін бастапқы күйінде (`\(x^2\)`) көрінеді — тест тоқтамайды.
- Жауап нұсқасы мәтін немесе сурет (не екеуі де) бола алады; екеуі де бос болса, сұрақ сақталмайды. Сурет — jpg / png / webp, 2 МБ-қа дейін (сұрақ суретіне де осы шек). Жауап суретінің файл аты кездейсоқ (`answers/<uuid>.png`), сондықтан аты дұрыс жауапты көрсетпейді.

## Мерзімі өткен тесттер

Тест уақыты біткенде (пәннің уақыты — 80 / 125 минут — немесе сессияның жабылуы) әрекет кез келген бетте ашылған сәтте өзі аяқталады. Студент бетті қайта ашпаса да нәтиже дұрыс көрінуі үшін серверде cron арқылы (мысалы, 5 минут сайын) мына команданы іске қосуға болады:

```powershell
.venv\Scripts\python manage.py finish_expired
```

## Аударма (қазақша / орысша)

Интерфейстің бастапқы мәтіні — қазақша, орысша аудармасы — `locale/ru/LC_MESSAGES/django.po`. Дайын `.mo` файлдары git-те бар, сондықтан жай іске қосу үшін ештеңе қажет емес.

Мәтін өзгерсе немесе жаңасы қосылса, GNU gettext керек (Windows: `winget install mlocati.GetText`, Ubuntu: `sudo apt install gettext`):

```powershell
# 1. Жаңа жолдарды .po файлдарына жинау
.venv\Scripts\python manage.py makemessages -l kk -l ru --ignore=.venv
# 2. locale/ru/LC_MESSAGES/django.po ішінде бос msgstr "" жолдарын аудару
# 3. .mo файлдарын жасау (оларды да commit жасаңыз)
.venv\Scripts\python manage.py compilemessages --ignore=.venv
```

## Жүктеме тесті (Locust)

[loadtest/locustfile.py](loadtest/locustfile.py) нақты студенттің жолын қайталайды: тест аккаунтымен кіреді → ашық сессияда тестті бастайды → 50 сұраққа 5–20 секунд аралықпен жауап береді → тестті аяқтайды. Бір виртуалды студентке — бір аккаунт (бір сессияда бір әрекет болғандықтан), сондықтан 1000 студентке 1000 аккаунт керек.

**Маңызды:** жүктеме тестін серверде (PostgreSQL + Gunicorn) жүргізіңіз. Жергілікті `runserver` + SQLite бір мезгілде жазуды көтермейді: бірнеше студент қатар жауап сақтаса, `database is locked` (HTTP 500) қатесі шығады. Жергілікті ортада тек скрипттің жұмысын 2–3 студентпен (`-u 3 -r 1`) тексеруге болады.

**1. Деректер** (сервердегі жобада; банкте тестке жететін сұрақ болуы керек):

```bash
sudo -u ozp .venv/bin/python manage.py loadtest_data --count 1000
# → Locust үшін: LOADTEST_SESSION_ID=7 LOADTEST_ACCOUNTS=1000

# Басқа пән бойынша (әдепкі — informatics; сол пәннің банкі толық болуы керек):
sudo -u ozp .venv/bin/python manage.py loadtest_data --count 1000 --subject mathematics
```

Команда `student001`–`student1000` аккаунттарын (`--count` әдепкісі — 100: `student001`–`student100`) және тек солардың «LOADTEST» тобына ашық сессияны жасайды; нақты студенттер бұл сессияны көрмейді. Аккаунттардың құпия сөзі — `loadtest-pass-2026` (`--password` арқылы өзгертуге болады). Қайта іске қосқанда бұрынғы әрекеттер өшіріледі де, сессия қайта ашылады.

**2. Locust** (өз компьютеріңізде, бөлек виртуалды ортада):

```powershell
python -m venv .venv-loadtest
.venv-loadtest\Scripts\python -m pip install -r loadtest/requirements.txt

$env:LOADTEST_SESSION_ID = "7"
$env:LOADTEST_ACCOUNTS = "1000"
# Windows gevent DLL-ін бұғаттаса (DLL load failed): $env:PURE_PYTHON = "1"
.venv-loadtest\Scripts\locust -f loadtest/locustfile.py --host https://test.example.kz --headless -u 1000 -r 5 --run-time 40m --html loadtest-report.html
```

- `-u 1000` — виртуалды студенттер саны (`LOADTEST_ACCOUNTS`-тан аспауы керек), `-r 5` — секундына қанша студент қосылады. Кіру кезінде құпия сөз тексеру процессорды көп жұмсайды, сондықтан студенттерді біртіндеп қосқан дұрыс.
- Nginx кіру бетіне шектеу қояды (бір IP-ден минутына 30 кіру, `deploy/nginx.conf`), ал Locust барлық студентті бір IP-ден кіргізеді: `-r 5` болса, кірулердің көбі 429 алады. Тест кезінде `rate=30r/m` мәнін уақытша көбейтіңіз (мысалы, `600r/m`, сосын `sudo nginx -t && sudo systemctl reload nginx`), тест біткен соң қайтарыңыз.
- Бір студенттің тесті шамамен 11 минут (50 × орташа 12,5 с). Барлығы аяқтағанда Locust өзі тоқтайды; `--run-time` — тек сақтық үшін.
- `--headless` жазылмаса, нәтижені браузерде көруге болады: http://localhost:8089 .
- Басқа баптаулар: `LOADTEST_PASSWORD`, `LOADTEST_LANGUAGE` (`kk` / `ru`), `LOADTEST_MIN_WAIT`, `LOADTEST_MAX_WAIT` (секунд).
- Locust-ты бір процесте іске қосыңыз (`--processes` жоқ): аккаунттар ретімен беріледі.

**3. Тазалау** (міндетті — аккаунттардың құпия сөзі белгілі):

```bash
sudo -u ozp .venv/bin/python manage.py loadtest_data --delete
```
